战锤3统帅战略修改器总控台 2.9.0（游戏内实时面板 + 战前静态包双模式）

验证状态：49项已记录游戏实测结果，其中部分为限定场景或原生引擎数值验证。最新补充实测范围见 output/deep-validation-20261030/补充实测结果.md；2.2.4 清理校验与真实界面截图见 output/ui-preview-20261030。

启动方式
- 双击“战锤3修改器.exe”打开双模式总控台；或双击“战锤3内置修改器安装器.exe”打开轻量安装中心。无需安装 Python。

模式一：游戏内原生实时修改面板（推荐）
1. 在“游戏内面板 (推荐)”分页中，可按需勾选要一并整合的附加模块（建筑快捷升级、AI 将军托管、全局战斗回血上限、敌方间谍减益、基斯里夫祈祷神器奖励、旧版全局弹道 / 爆炸覆盖），不勾选则生成 100% 纯净面板。
2. 点击“安装游戏内实时面板 (推荐)”。
3. 启动游戏进入单人战役，推荐点击顶栏右侧“修改器”入口打开面板；面板快捷键提示为 F9。
4. 支持被动加成实时开关与数值调整（生命值加成仅作用于我方领主与英雄），以及即时战略指令（国库加钱、全军/选中角色行动力恢复、选中/全军加经验、一键战役/战斗预设）。详见“内置修改器说明.txt”。
5. 行动力恢复为单次补满。“选中角色行动力恢复”和“选中角色注入经验”要求先选中我方在役领主或英雄；未选中、目标失效或选择敌方时会提示且不执行，不会自动作用于全军。

附加模块用途
- 全局战斗回血上限：默认值 50 表示累计回血池为单位最大生命的 50 倍，并非无限，也影响敌方；它与战役每回合补员上限是不同功能。
- 基斯里夫祈祷神器奖励：仅人类玩家的基斯里夫势力可在启动四神祈祷时获得对应神器；支持现版军队／行省入口与旧版入口，保留原生消耗、冷却与祈祷效果。现版行省祈祷消耗本行省虔诚，具体条件以游戏原生提示为准。
- 旧版全局弹道 / 爆炸覆盖：保留信鸽包旧数值，包含加强与削弱，也影响敌方，不能理解为全部弹道均获增强。

模式二：战前静态 Mod 配置包（兼容旧版固定难度表打包）
1. 确认游戏安装目录和“参考 Mod 目录”（默认即当前目录）。
2. 在“内政”、“军队”、“战斗”、“Mod 整合”分页中勾选所需功能并调整滑块/数值框。
3. 点击“生成静态配置包”或“生成并安装静态包”，重启游戏后生效。
   静态属性数值覆盖原难度的同项加成，不是额外叠加。例如原难度本地招募 +1 改为 10，净增为 9；本次南皋原生容量从 2 变为 11。游戏内面板 +10 则从 2 变为 12。
4. 静态包的“复活”必须同时开启持续回血；单独勾选时会提示并阻止生成。
   自定义持续回血、复活与补弹为每队己方部队仅作用自身的每秒被动，不向其它部队传播或重复叠加。
   护甲数值按点数增加，例如 70 护甲设置 100 后为 170，并非增加 100%。
   远程伤害加成只影响直接弹丸的基础与破甲伤害，不影响爆炸伤害；较小伤害会按游戏规则取整。
   链锯剑是随自身真实击杀增长伤害的被动，无需点击施放；没有击杀时不提供伤害增幅。
5. 旧版三档复合预设的实际参数依次为：每 3 秒回血 1% 并补弹 5%、每 3 秒回血 1.5% 并补弹 20%、每 3 秒回血 2% 并补弹 50%。
6. 旧预设已移除不能增加实战储量的魔风界面覆盖；回血、复活、补弹、冻结疲劳及战斗属性保留。原始参考包保留用于兼容既有配置，不直接安装。

2.3.0 界面重构
- 桌面总控台与安装器全部重做：左侧导航分区（游戏内面板 / 静态配置包 / 其他），每页只保留一个主要操作；静态包页底部固定「生成 / 生成并安装」操作栏。
- 新增全局搜索（Ctrl+F）、收藏、「已启用」汇总页；数值项用开关 + 滑块 + 输入框，拖动或输入时自动开启。
- 支持高分屏：按系统缩放自动放大，文字清晰不发虚。
- 游戏内面板重新排版：控件按 UI 缩放自动放大，放不下的文字先换小字号再截断；标题栏新增「缩放」按钮可手动指定 100%～200%。

2.2.4 清理
- 从三档复合预设生成结果中删除无实际储量效果的魔风界面参数，并清理界面中的相关功能说明。
- 修复独立安装器默认窗口内容截断：附加模块说明自动换行，内容可滚动，操作栏固定在底部。
- 所有界面预览见 output/ui-preview-20261030；此前补充实测证据见 output/deep-validation-20261030。

2.2.3 补充修复
- 基斯里夫神器奖励补齐现版军队／行省四神祈祷入口；保留旧入口兼容性和当前游戏的原生消耗、冷却与效果。
- 军队移动距离提示明确为下个我方回合刷新；单独行动的事务官不受影响。
- 补充静态难度覆盖值说明，明确它与游戏内额外叠加的区别。

2.2.2 兼容性修复
- 修复调用游戏不支持的 UIComponent:SetPriority 导致面板无法打开的问题，改用原生支持的优先级接口。
- 修复游戏 Lua 环境缺少 math.huge 导致数值校验报错、加钱等指令无法执行的问题。
- 修正本地招募格子加成，增加我方行省本地招募容量；旧引用效果控制游牧招募容量，不适用于普通军队的本地招募。
- 修正生命值加成的作用对象，明确为我方领主与英雄生命值，普通部队生命值不变。
- 修复选中角色指令在没有有效目标时误作用全军的问题，改为提示先选择在役角色；选中角色行动力恢复为单次补满。
- 战斗类属性可能在战役兵牌中仍显示基础值，请进入战斗核对。实测近战攻击基础 20、面板加成 20 后，手动战斗部署阶段显示 40。

游戏更新后
- 修改器包是自动加载类型，启动器里关不掉。游戏更新后请先打开安装器：提示“需要重新适配”时点击“重新适配并安装”；暂时无法适配时点击“卸载”，保证游戏能启动。
- 联机前请先卸载。修改器包在联机时同样会被加载，可能导致不同步（未实测）。

文件与架构说明（均在 src/ 下）
- app.py                 双模式桌面总控台（侧栏导航 / 安装与启动 / 静态包分类 / 已启用 / 设置）
- ui_kit.py              桌面端共享界面组件（高分屏适配、圆角按钮、开关、滑块、搜索框）
- ingame_installer.py    独立游戏内面板安装中心（支持附加模块可选打包）
- build_ingame.py        游戏内面板 Pack 构建器与离线预览渲染器
- game_compat.py         记录并比对 Pack 依赖的游戏数据，判断游戏更新后是否需要重新适配
- shop_addon.py / ingame/shop_reward.lua  基斯里夫四神祈祷神器奖励整合与发放
- ingame/panel.lua       游戏内原生 Lua 抽屉界面、被动加成回读与即时战略指令
- ingame/income.lua      每回合收入增幅
- trainer_core.py        静态配置包合并、表版本迁移、安全安装/备份/卸载
- attributes.py          20 项难度表属性定义与校验
- pack_io.py / database.py  PFH5 Pack 与数据表编解码
构建方法见 README.md。
